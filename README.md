# 언젠가, 닿을, 저 하늘에. 한글패치

PC판용 한글패치입니다. 공식 2.00 업데이트와 PS2 추가 콘텐츠를 통합했습니다.

## 다운로드

**[최신 한글패치 R9.1 다운로드](https://github.com/adios1579-lgtm/Itsusora-Korean-Patch/releases/tag/v2026.09.17-r9)**

릴리스의 Assets에서 `Itsusora_Korean_Patch_20260919_R9.1.zip` 하나를 받으세요. GitHub의 `Source code` 파일은 설치용 패치가 아닙니다.

## 설치

1. ZIP 파일을 전부 풉니다.
2. 게임 종료 후 **한글패치 설치.exe**를 실행합니다.
3. 원본 PC판 또는 이전 한글패치가 설치된 게임 폴더를 선택합니다.
4. 설치 완료 후 게임 폴더의 **한글판 실행.exe**로 실행합니다.

공식 2.00을 따로 받을 필요가 없습니다. 일본어 설치 폴더명을 그대로 사용할 수 있습니다. 원본 PC판이 필요하며 게임 전체 파일은 포함하지 않습니다.

## 주요 내용

- PS2판 메메 공략 루트·후일담·추가 CG·전투 CG
- 한국어 본문·선택지·UI 및 한글 타이틀
- 원작에 없던 하단 퀵메뉴
- 한글 오프닝 2편과 영상 잔상 수정
- 공식 2.00 통합 및 일본어 설치 경로 지원

## R9.1 수정사항

- PS2 추가 장면의 스탠딩 입장·퇴장·표정 변경을 PC판 방식으로 변경
- 기존 세이브의 스탠딩 겹침·대사 표시 호환성 수정
- 기존 R9 배경 이미지 한글화 및 호칭관련 수정 포함

기존 세이브는 저장했던 장면을 이전 연출로 재개하고, 다음 PS2 장면부터 PC판 전환을 적용합니다.

## R9 수정사항

- 누락된 묘비 배경 이미지 2종 한글화
- 비석에 어울리도록 글자 질감 조정

## 세이브와 복구

기존 세이브 파일은 보존합니다. 다만 **공식 2.00 안내상 이전 버전 세이브는 호환되지 않습니다.**

설치 전 파일은 `_KO_backup_...` 폴더에 보관합니다. 게임 종료 후 배포 폴더의 **패치 복구.exe**에서 게임 폴더와 백업을 선택해 복구할 수 있습니다. 백업 폴더의 `restore.cmd`도 사용할 수 있습니다.

자세한 안내와 오픈소스 라이선스·대응 소스는 배포 ZIP에 포함되어 있습니다.
